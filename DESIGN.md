# Little Cart

A simple, independent shopping demo. This replaces the former marketplace imitation at the user's request.

Use white surfaces on a light gray background, dark slate text, and teal (#0f766e) for primary actions and selected controls. The logo combines a drawn cart with the Little Cart wordmark; never use the smile-arrow, orange/yellow marketplace palette, or lookalike branding.

The storefront is an operating interface: one search in the header, a concise introduction, category filters, and a responsive product grid. Mobile search takes its own full-width row. Product photos remain central. Keep account, orders, admin, and API-key functions accessible. Prices remain INR.

Label the application as a shopping demo and state that payments create no real charges. Keep backend/security implementation details out of the main shopping flow. Use existing system sans typography, clear focus states, borders for grouping, and restrained spacing.
